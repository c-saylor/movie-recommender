# MovieMatch

A personalized movie discovery app that combines TMDb data with AI-powered recommendations. Browse popular films, build your favorites and watchlist, then let the AI find your next watch based on your taste and mood.

---

## Features

- **AI Recommendations** — Describe what you're in the mood for, pick mood tags, and get five curated picks generated by Llama 3.1 via Groq
- **TMDb-based Recommendations** — Automatically surfaces similar and recommended films based on your favorites list
- **Browse & Search** — Infinite-scroll catalog of popular movies with live search autocomplete
- **Filter & Sort** — Filter the full catalog by genre, minimum rating, and sort by title, release date, or rating
- **Movie Detail Modal** — Animated overlay with genre tags, rating, overview, and action buttons
- **Favorites / Watchlist / Not Interested** — Persistent lists stored in `localStorage`
- **Responsive layout** — Works across desktop and mobile viewports

## Getting Started

### Prerequisites

- Node.js 18+
- A [TMDb API read access token](https://developer.themoviedb.org/docs/getting-started)
- A [Groq API key](https://console.groq.com/) (free tier is sufficient)

### Installation

```bash
git clone https://github.com/your-username/movie-recommender.git
cd movie-recommender
npm install
```

### Environment Variables

Create a `.env` file in the project root:

```env
# TMDb read access token (JWT — found in TMDb account settings under API)
REACT_APP_TMDB_API_KEY=your_tmdb_read_access_token_here

# Groq API key
REACT_APP_GROQ_API_KEY=your_groq_api_key_here
```

> Both keys are only used client-side. The TMDb token is a JWT read-access token, **not** the shorter v3 API key.

### Running the App

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
